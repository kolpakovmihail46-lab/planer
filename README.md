# Планировщик

Личный планировщик: встречи и обязательные задачи, ссылки на документы, двусторонняя синхронизация с Google Календарём и голосовые команды через Claude. Устанавливается на Android как приложение (PWA). Часовой пояс — Омск.

Адрес: https://kolpakovmihail46-lab.github.io/planer/

## Как это устроено

- Сервера нет. Приложение работает в браузере и напрямую обращается к Google Календарю и к Claude.
- Встречи и задачи хранятся как события в Google Календаре. Задача без времени — событие на весь день, выполненная задача помечается «✓» в названии. Ответственный и ссылки видны в описании события.
- Изменения, сделанные в Google Календаре, подтягиваются при открытии приложения и по кнопке ⟳.
- Голосовая команда: речь → текст (распознавание Chrome) → Claude разбирает команду в действия → приложение показывает, что изменится, и сохраняет только после «Подтвердить».
- Ключи (Google Client ID и ключ Anthropic) вводятся в настройках и хранятся только в браузере телефона. В репозитории их нет.

## Что нужно один раз настроить

### 1. Google Календарь через Apps Script (бесплатно, без карты и Google Cloud)

Удобнее делать с компьютера, один раз.

1. Откройте планировщик → ⚙ Настройки → «Через Apps Script» → «Скопировать скрипт».
2. Откройте https://script.google.com/home/projects/create под своим Google-аккаунтом, удалите всё в редакторе и вставьте скрипт.
3. Слева у «Сервисы» нажмите **＋** → **Google Calendar API** → «Добавить».
4. «Сохранить» → выберите функцию `authorize` → «Выполнить». Google попросит доступ: «Проверить разрешения» → аккаунт → «Дополнительно» → «Перейти к проекту» → «Разрешить». Предупреждение «приложение не проверено» нормально: это ваш собственный скрипт.
5. «Развертывание» → «Новое развертывание» → тип «Веб-приложение». Запуск от имени: **Я**. Доступ: **Все**. «Развернуть».
6. Скопируйте URL веб-приложения (заканчивается на `/exec`), вставьте в настройках и нажмите «Подключить Google».

Скрипт защищён ключом доступа, который вписан в него автоматически. Если скрипт настроен на компьютере, на телефоне введите в настройках тот же ключ и тот же URL.

<details><summary>Запасной вариант: OAuth Client ID в Google Cloud</summary>

1. https://console.cloud.google.com/projectcreate — создайте проект (баннер с предложением ввести карту можно закрыть).
2. Включите **Google Calendar API**: https://console.cloud.google.com/apis/library/calendar-json.googleapis.com
3. «Google Auth Platform»: тип **External**, добавьте свою почту в **Test users**, scope `.../auth/calendar.events`.
4. «Clients» → «Create client» → **Web application**, в **Authorized JavaScript origins**: `https://kolpakovmihail46-lab.github.io`
5. Вставьте Client ID в настройках (вкладка «OAuth Client ID»). В этом режиме Google просит войти заново примерно раз в час.
</details>

### 2. Ключ Anthropic API

1. https://console.anthropic.com/ → «API Keys» → «Create Key».
2. Пополните баланс (Billing). Одна голосовая команда стоит порядка одного-двух центов.
3. Вставьте ключ в настройках приложения.

### 3. Установка на Android

Откройте адрес в Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение». Разрешите доступ к микрофону при первой голосовой команде.

## Примеры команд

- «Встреча с поставщиком рыбы завтра в 11»
- «Задача: проверить остатки лосося до пятницы, поручи Ивану»
- «Перенеси планёрку на четверг в 15:00»
- «Отметь выполненной задачу про остатки»
- «К задаче про меню добавь ссылку docs.google.com/…»
