# Планировщик

Личный планировщик: встречи и обязательные задачи, ссылки на документы, двусторонняя синхронизация с Google Календарём и голосовые команды через Claude. Устанавливается на Android как приложение (PWA). Часовой пояс — Омск.

Адрес: https://kolpakovmihail46-lab.github.io/planer/

## Как это устроено

- Сервера нет. Приложение работает в браузере и напрямую обращается к Google Календарю и к Claude.
- Встречи и задачи хранятся как события в Google Календаре. Задача без времени — событие на весь день, выполненная задача помечается «✓» в названии. Ответственный и ссылки видны в описании события.
- Изменения, сделанные в Google Календаре, подтягиваются при открытии приложения и по кнопке ⟳.
- Голосовая команда: речь → текст (распознавание Chrome) → Claude разбирает команду в действия → приложение показывает, что изменится, и сохраняет только после «Подтвердить».
- Ключи (Google Client ID и ключ Anthropic) вводятся в настройках и хранятся только в браузере телефона. В репозитории их нет.

## Что нужно один раз настроить

### 1. Google OAuth Client ID (бесплатно, ~10 минут)

1. Откройте https://console.cloud.google.com/ и создайте проект, например «Планировщик».
2. «APIs & Services» → «Library» → найдите **Google Calendar API** → «Enable».
3. «APIs & Services» → «OAuth consent screen» (Google Auth Platform): тип **External**, название «Планировщик», ваша почта. В «Audience» добавьте свою почту в **Test users**. В «Data access» добавьте scope `.../auth/calendar.events`.
4. «Clients» (Credentials) → «Create client» → тип **Web application**.
   В **Authorized JavaScript origins** добавьте: `https://kolpakovmihail46-lab.github.io`
5. Скопируйте **Client ID** (вида `1234-abc.apps.googleusercontent.com`) и вставьте в настройках приложения, затем нажмите «Подключить Google».

Пока приложение в статусе «Testing», Google может раз в несколько дней просить войти заново — это нормально для личного использования.

### 2. Ключ Anthropic API

1. https://console.anthropic.com/ → «API Keys» → «Create Key».
2. Пополните баланс (Billing). Одна голосовая команда стоит порядка одного-двух центов.
3. Вставьте ключ в настройках приложения.

### 3. Установка на Android

Откройте адрес в Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение». Разрешите доступ к микрофону при первой голосовой команде.

## Примеры команд

- «Встреча с поставщиком рыбы завтра в 11»
- «Задача: проверить остатки лосося до пятницы, поручи Ивану»
- «Перенеси планёрку на четверг в 15:00»
- «Отметь выполненной задачу про остатки»
- «К задаче про меню добавь ссылку docs.google.com/…»
